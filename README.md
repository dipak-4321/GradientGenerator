# 🎨 Gradient Generator

A modern and interactive **Gradient Generator** built with React and Vite. This project allows users to generate random, beautiful color gradients and linear gradients, customize their experience, and easily copy the generated CSS code for use in their own projects.

## ✨ Features

- 🎨 **Random Color Generation** — Generate different color combinations every time.
- 🌈 **Gradient Options** — Choose between Gradient and Linear gradient modes.
- 🖌️ **Live Preview** — View the generated gradient colors instantly.
- 📋 **Copy CSS Code** — Copy the generated gradient CSS code with a single click.
- 🔢 **Input Field** — Enter a value to control the generation process.
- ⚡ **Fast and Responsive** — Built with React and Vite for a smooth experience.
- 💻 **Simple Interface** — Easy-to-use controls and a Generate button.

## 🛠️ Technologies Used

- **React** — For building the user interface.
- **Vite** — For fast development and building the project.
- **JavaScript** — For gradient generation and interactive functionality.
- **CSS / Tailwind CSS** — For styling and layout, depending on the styling used in the project.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your repository's actual URL.

### 2. Navigate to the Project Folder

```bash
cd gradient-generator
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application in your browser.

## 📖 How to Use

1. Open the Gradient Generator application.
2. Choose your preferred gradient type from the available options.
3. Enter a value in the input box if required.
4. Click the **Generate** button to create a new color gradient.
5. Preview the generated gradient on the screen.
6. Click the **Copy** button to copy the CSS color code.
7. Generate again to explore new color combinations.
